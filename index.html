개인 일정 도우미는 운영자 본인의 Google 캘린더를 조회하고, 일정 제목과 시간을 개인용 텔레그램 브리핑에 덧붙이는 도구입니다. 일반 사용자를 모집하는 서비스가 아닙니다.

개인정보처리방침 확인
01 · 조회

선택한 캘린더만

사용 권한이 있고 연동 대상으로 지정한 캘린더를 조회합니다. 브리핑에는 캘린더 표시 이름, 일정 제목, 날짜와 시간을 사용합니다.

02 · 처리

Google 일정은 변경 없이

이 연동의 Google 캘린더 기능은 읽기 전용입니다. Google의 일정 생성·수정·삭제 기능은 사용하지 않습니다.

03 · 전달

개인 텔레그램 브리핑

조회 결과를 정리해 운영자가 지정한 텔레그램 대화에 보냅니다. 전송한 메시지는 해당 대화에 남을 수 있습니다.

연결과 데이터 흐름

Google Calendar → 운영자 컴퓨터 → 지정된 Telegram 대화

Google 계정 연결은 운영자 컴퓨터의 OAuth 인증 절차에서 진행합니다. 이 안내 사이트에는 Google 로그인, 일정 조회, 계정 등록 또는 결제 기능이 없습니다.

Google 캘린더에서 읽은 일정은 참고용 브리핑에 사용합니다. 별도로 관리하는 로컬 할 일·일정과 Google 일정을 자동으로 서로 생성하거나 동기화하지 않습니다.

이 사이트에 개인 일정은 게시하지 않습니다.
공개되는 것은 앱 설명과 개인정보처리방침입니다. 일정 내용, 캘린더 식별자, OAuth 토큰, API 키와 프로그램의 운영 파일은 이 사이트에 포함하지 않습니다.
